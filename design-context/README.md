## 先修正三個容易混淆的背景

1. **現行不是 5×5。** 小陣是 7×7、每方 8 枚、5 種棋；大陣是 9×9、每方 13 枚、8 種棋。5×5、同質棋、留下方向箭頭的是已離開的 S0 原型。
2. **現行棋名是主、兵、騎、鬼、鴉、熊、蟬、狐。** 不要用 King／Bishop／Rook 等程式或歷史對照名稱推論現行走法。
3. **立體棋沒有被證實是手機效能失敗。** 即時 3D 載入 spike 與盤上立體棋的辨識實驗是兩件事；後者沒達辨識標準，製作人已改選「盤上印鈕＋面板人偶＋關鍵特寫」。
