# 《借勢・疊陣》主將（四天王）規則 v1（2026-10-27，先給模擬用）

> 製作人裁定：主將能力用「累積能量→秘技」，能量只靠「封住對方」累積（製作人回「改」）；四招照建議（製作人回「可以 先這個方向看開工」）。
> 適用範圍：只用在 G2 正式盤，規則採 capture-home（打回陣地）。沒寫到的部分，一律照 RULES_G1／G2／CAPTURE（含釋疑）。
> 出處分三層：史實、傳說、原創。四招的「效果」全部是原創，只有招名和意象取自傳說。

## Z-1 主將
- 開局時，雙方各選一位主將，也可以選「無」。主將就是「主」這顆棋，走法和其他規則都不變。
- 四位主將：渡邊綱、坂田金時、碓井貞光、卜部季武。

## Z-2 能量
- 雙方都從 0 開始，上限 3，雙方的能量都公開。
- **只有「封住對方」會增加能量**：你的一個動作（移動，或依照 Z-4 說明）結束後，只要你的棋直接壓在一顆敵棋上方，而且這顆敵棋以前從沒讓你得過能量，你就 +1。到 3 為止，不會再往上加。
  - 「直接壓在上方」：那顆敵棋正上方的那一顆，是你的棋。
  - 每顆敵棋以棋子 id 計算，一局只算一次。倒戈之後 id 不變，這顆棋不會因為換邊再算一次。
  - 自己的棋疊在自己的棋上，不算封住。
  - 秘技本身造成的封住，不加能量。
- 能量計入局面鍵（雙方各一個數字）。

## Z-3 秘技
- 輪到你、而且你的能量剛好是 3 時，你可以改成發動秘技，這一手就不移動、也不召喚。
- 發動時，能量先歸零，再結算效果。
- **全域限制**：秘技一律不能指定、移動、收服、推動、凍結任何一方的主，也不能讓任何棋落到主上，所以秘技不能直接獲勝。
- 秘技造成某顆棋落到別的棋上時，照一般的落下規則處理：封住、疊到 3 層就收服（收服的棋歸發動方）、敵棋落到狐身上就倒戈。
- 合法動作＝移動＋召喚＋秘技。如果沒有任何合法動作，就判負。

## Z-4 四招
距離一律用「8 方向距離」：橫、豎、斜各算 1，也就是 Chebyshev 距離。

1. **渡邊綱「鬼切」**
   - 選一疊，條件有三：離你的主 2 格以內；最上面是敵棋；緊貼在它下面的那顆是你的棋。
   - 把最上面那顆敵棋取下，收服到你的手上。下面的棋留在原地，這一疊最上面變回你的棋，等於把它救出來。

2. **坂田金時「相撲」**
   - 選一顆離你的主 1 格以內的敵棋，它必須在那一疊的最上面，再選 8 個方向中的一個。
   - 把它往那個方向推 1 格：
     - 目標格是空格，就直接移過去。
     - 目標格有棋，就疊上去，照常封住、疊到 3 層收服、落到狐上倒戈。
   - 不能推出棋盤；目標格裡有主時，不能推。
   - 這顆棋原本壓住的棋，恢復自由。

3. **碓井貞光「一矢」**
   - 選一顆緊貼在你的主旁邊、1 格以內的己方棋，它必須在那一疊的最上面，而且不是主。方向就是「主 → 這顆棋」。
   - 這顆棋沿這個方向往外飛，依序看離它 1、2、3、4 格的位置，找到第一格有棋的格子：
     - 那一格最上面是敵棋，而且不是主，這顆棋就落上去，照常封住、收服、倒戈。
     - 那一格最上面是自己的棋或主，或 4 格內都沒有棋，就不能這樣發動。
   - 飛行路徑只看格子有沒有棋，不會被借勢或其他規則影響。

4. **卜部季武「奪子」**
   - 選一顆敵棋，條件是它正上方那一顆是你的棋，也就是被你封住的敵棋，棋盤上任何位置都可以。
   - 這顆敵棋永久倒戈，變成你的棋，位置和疊的順序都不變。

## Z-5 其他
- 秘技算一個半回合，會計入半回合上限。
- 重複局面的判斷，局面鍵要包含能量。

## Z-6 釋疑 v1.1（2026-10-27，借勢驗收冷讀後補；和上文衝突時以本段為準）
1. **棋子 id**：開局時每顆棋都有自己的 id。被收服進手上，id 就作廢；從手上召喚上場時，給一個新的 id。倒戈和奪子都保留原本的 id。
2. **登記與能量**（取代 Z-2 原本的判定方式）：
   - 每個動作結束後掃描全盤。這裡的動作包括任何一方的移動、召喚、秘技。
   - 只要有「X 方的棋緊貼壓在 Y 方的棋上方」（X 和 Y 不同方），而這顆 Y 方棋的 id 還沒被 X 方登記過，就替 X 方登記這個 id。
   - 只有當這個動作是 X 方自己的「移動」時，X 方每登記一個 id，能量就 +1，到 3 為止。如果是召喚、秘技，或對方的動作造成的，只登記、不加能量。
   - 能量已經是 3 時登記的 id，一樣算用掉，之後不會再補加。
   - 例：對方用相撲，把我的棋推到他的棋上，變成我的棋壓著他的棋 → 替我登記，不加能量。在打回陣地規則下，「對方的動作替我登記」只會在這種情況發生。
   - （v1.1 原本另有兩個蟬的例子，已經刪掉。原因：靜止時一疊最多 2 層，被壓住的蟬一定在最底下，溜走之後不會有棋掉到敵棋上，所以那兩個例子在打回陣地規則下不會發生。借勢驗收冷讀時指出。）
3. **「無」沒有能量**：選「無」的一方，能量永遠是 0，也不能發動秘技。
   - 局面鍵：雙方都是「無」時，局面鍵和既有版本逐字相同；只要有一方選了主將，局面鍵就再加上雙方的能量。
   - 已登記的 id 集合，不放進局面鍵。
4. **秘技移動的棋**：不受那顆棋本身走法的限制（例如狐本來不能踩敵棋），只受 Z-3 的全域限制和一般的落下結算（最多 3 層、收服、倒戈）。被移走的棋原本壓住的棋，恢復自由。
5. **倒戈**：照現行規則，落到狐上的棋，改歸狐的主人；落到自己這方的狐上，不會倒戈。
   - 相撲：可以把敵棋推到你方的狐上，那顆就變成你的；也可以推到其他任何棋上。
   - 一矢：不能選狐當箭。飛行路上第一個有棋的格子，最上面那顆必須是敵方的棋、不是主、也不是狐，才能發動。如果是狐，箭就被擋下（狐擋箭）。
6. **奪子**：那顆敵棋改歸你方，之後照一般規則處理。例如它之後落到敵方的狐上，一樣會再倒戈。
7. **刪掉 Z-3 的「凍結」**：沒有任何一招會凍結棋。秘技不檢查自己的主會不會因此暴露，現行規則本來就沒有這種限制。
9. **引擎第一階段的疑點裁定**（2026-10-27，主 session）：
   - 「無」那一方不登記任何 id，已登記數永遠是 0。
   - 雙方都是「無」時，召喚沿用舊引擎的 id 規則，讓事件和舊版逐字相同。只要有一方選了主將，召喚就依序給新的 id，從 27 開始。
   - 踩主獲勝的那一手，照樣掃描登記。勝負不受影響。
   - 如果 C10 把一矢的範圍改成主周圍 2 格，只取主周圍 8 條線上的格子（橫、直、斜），方向仍然是 8 方向之一。
8. **紀錄參數**：鬼切 {sq}（被斬的那一疊）、相撲 {sq, dir}、一矢 {sq}（當箭的那一顆）、奪子 {sq}。靜止時一疊最多 2 層（第 3 顆落下時，最底下那顆就被收服），所以只用格名就能唯一指定。

## Z-7 第二輪候選 v2（2026-10-27；製作人回「照這樣」，依據 GPT #03）
> 第一輪 v1 的結果：C8 可用率沒過（綱 5.5%、金時 13.5%、貞光 5.7%）。v2 的做法是每一招只放寬一個主要限制。奪子、能量規則（Z-2、Z-6.2）、全域限制（Z-3）都不改。v1 保留，當作對照組；引擎用 `cmdRules: 'v1' | 'v2'` 切換，預設是 v1。

**共同規則（v1 本來就是這樣，這裡只是寫明）**
- 在你的回合開始時，如果你持有 3 點能量，可以把能量全部用掉、發動一次秘技，用來取代這一手原本的行動。
- 能量可以保留到之後再用。
- 沒有合法目標時不能發動。
- 秘技不能指定任何一方的主，也不能讓棋子落到主所在的格子。
- 秘技造成的封住只登記、不加能量（Z-6.2，維持不變）。

**v2 鬼切**
- 可以選全盤任何一疊，條件是：最上面是敵棋，而且緊貼在它下面的是你的棋。
- 那顆敵棋被收服到你手上，原本被壓住的你的棋變成最上面。
- 跟 v1 唯一的差別：取消「離主 2 格以內」的限制。

**v2 相撲**
- 選一顆最上面的敵棋，它離你的主不能超過 2 格（8 方向距離）。
- 把它往 8 個方向之一推 1 格，其餘規則照 v1：不能推出盤外，目標格有主時不能推，推到有棋的格子就照常結算。
- 跟 v1 唯一的差別：選目標的範圍從 1 格放寬到 2 格。推的距離還是 1 格。

**v2 一矢**
- 選任何一顆非主的己方棋當箭，它必須是那一疊最上面那顆，不能是狐（Z-6.5）。然後選 8 個方向之一。
- 從箭所在的格子往那個方向，依序看第 1 到第 4 格（不算原格），找出第一個有棋的格子：
  - 那一格最上面是敵棋，而且不是主、也不是狐：箭（也就是那顆棋本身）飛到那一疊的最上面，照常結算；
  - 碰到己方最上層的棋、狐或主，或是 4 格內都沒有棋：這個方向不能發動。
- 只有最上面那顆棋會飛走，它原本壓住的棋留在原地，恢復自由。
- 跟 v1 的差別：取消「箭必須緊貼主」和「方向必須是主→箭」這兩個限制。
- 紀錄參數改成 {sq, dir}。

**v2 奪子**：跟 v1 相同。
- **Z-7 補充**（借勢驗收冷讀後）：
  - 一矢的紀錄參數是 {sq, dir}，dir 寫成 [dx,dy]，格式和相撲一樣。
  - 沿著方向還不到 4 格就碰到盤邊，而且途中沒有任何棋：這個方向不能發動，視同「4 格內沒有棋」。
  - 第一個有棋的格子，最上面如果是己方的棋（包括己方的狐、主），箭就被擋下。如果是敵方的狐或主，也一樣擋下。如果是其他敵棋，箭就落上去，那一疊下面壓的是什麼都沒關係。
